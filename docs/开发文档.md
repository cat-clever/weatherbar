## 1. 项目概述

### 1.1 产品定位

一个常驻 macOS 菜单栏的轻量天气工具：

- **零窗口**：不开 Dock、不占屏，状态栏一行字即全部信息。
- **一眼可见**：图标 + 当前温度常驻菜单栏，随天气自动换图标。
- **点开即详**：单击弹出深色玻璃面板，展示当前实况、逐小时、逐日、日月、风速湿度曲线。
- **原生**：纯 SwiftUI + AppKit，无 Electron、无 WebView，内存 < 80 MB，冷启动 < 300 ms。

**视觉特征**

- 深紫蓝渐变背景，卡片为半透明白（约 6~8% 不透明度）叠层。
- 温度数字极大（约 76 pt）、超细字重，其余文字 12~15 pt。
- 图标为彩色 3D 质感天气图标；本产品改用 SF Symbols 多色调（palette）渲染，保持原生一致性。
- 降水概率用蓝色强调文字（`59%` / `36%`）。
- 圆角 12~14 pt，区块间距 10 pt，内边距 12~14 pt。

## 2. 技术选型

### 2.1 技术栈

| 层 | 选型 | 理由 |
|---|---|---|
| 语言 | Swift 6.1（Swift 6 语言模式） | 严格并发，`@MainActor` 隔离干净 |
| UI | SwiftUI（内容）+ AppKit（状态栏/弹窗宿主） | SwiftUI 写面板极快；`NSStatusItem` 控制力强 |
| 状态管理 | `ObservableObject` + `@Published` | macOS 13 兼容（`@Observable` 需 14，为覆盖 Intel 老机放弃） |
| 架构 | Universal 2（`arm64` + `x86_64`） | 单包双架构，Intel 与 Apple Silicon 均原生运行 |
| 图表 | Swift Charts | 原生、支持平滑曲线 + 渐变面积（macOS 13+） |
| 网络 | `URLSession` + `async/await` + `Codable` | 无第三方依赖 |
| 定位 | CoreLocation + `CLGeocoder` | 系统原生，反查地名 |
| 持久化 | `UserDefaults`（偏好）+ 沙盒内 JSON（快照缓存） | 数据量小，无需 CoreData |
| 依赖注入 | 轻量手写（init 注入协议） | 无 SPM 第三方包，构建快 |

> **零第三方依赖**是硬约束：CI 上无需 `swift package resolve` 拉包，构建稳定、产物体积小（< 3 MB）。

### 2.2 状态栏实现方案对比

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| `MenuBarExtra`（SwiftUI） | 代码最少，`.window` 样式自动 | 弹窗尺寸/圆角/阴影不可控；无法自定义右键菜单；无法精确控制 popover 外点击行为；文字+图标混排受限 | 备选（快速原型） |
| `NSStatusItem` + `NSPopover` + `NSHostingController` | 完全可控：自定义 contentSize、圆角、材质、右键菜单、滚轮事件、外点关闭 | 需手写 ~150 行宿主代码 | **采用** |
| `NSStatusItem` + `NSWindow`（无边框） | 可做非模态悬浮面板 | 焦点/层级管理复杂 | 不采用 |

**选定**：`NSStatusItem` 宿主 + SwiftUI 内容。

### 2.3 工程与构建方式

| 方案 | 说明 | 采用 |
|---|---|---|
| A. 纯 SPM executable + 手工打 bundle | `swift build` 即出二进制，脚本拼 `.app` | 不采用（需本地编译） |
| B. **XcodeGen（`project.yml`）→ `xcodebuild`** | 工程声明式、无 `.xcodeproj` 冲突、CI 一条命令 | **采用** |
| C. 手写 `.xcodeproj` | 易冲突、不可读 | 不采用 |

- `project.yml` 入库，`WeatherBar.xcodeproj` 由 `xcodegen generate` 生成并加入 `.gitignore`。
- **CI 单点构建**：`xcodebuild` 只在 GitHub Actions 上执行，本地不产出任何二进制（见 §10.4）。

**规则**

- 视图层不直接 `URLSession`，只读 `WeatherStore`。
- `WeatherStore` 是唯一 `@MainActor` 状态源；网络/计算在 `actor` 或后台任务中完成，回主线程写入。
- 所有服务面向协议，便于注入假数据做 SwiftUI Preview 与单测。

### 3.4 关键时序

**启动**

```
launch → AppDelegate.applicationDidFinishLaunching
  ├─ 读 PreferencesStore（单位、刷新间隔、天气源）
  ├─ 读 PlaceStore（地区列表 + 当前地区）
  ├─ 读 SnapshotCache（按 providerID-placeID）→ 立即渲染状态栏（stale 也先显示）
  ├─ StatusItemController 装配（item / popover / 菜单 / 监听器）
  ├─ RefreshScheduler.start()
  ├─ Task { await store.refresh() }              // 首次真实拉取
  └─ 1s 后 OnboardingController.showIfNeeded()   // 仅首次
```

**首次引导**

```
showIfNeeded()
  ├─ onboarding.version < 1 ? 否 → 结束
  ├─ 取 statusItem.button 的屏幕矩形
  ├─ 建 NSPanel（borderless / statusBar+1 / 透明）
  ├─ 定位：x = item.midX - 160（夹紧到屏幕内），y = item.minY - 高度 - 8
  ├─ 淡入 0.22s
  └─ 3 步：我在这里 → 点一下看详情 → 选地区
        完成 → 写 onboarding.version=1 → 淡出 → 自动打开主面板
```

**切换地区**

```
用户点地区名 → route = .regionSwitcher
  → 点列表某项 → PlaceStore.setActive(id)
      ├─ 写 activePlaceID
      ├─ 若 cache/<providerID>-<id>.json 存在 → 先 apply（秒显）
      ├─ WeatherStore.refresh()
      │    ├─ ProviderRegistry.resolve(preference, place)
      │    ├─ provider.fetch() 失败 → 降级链下一个源
      │    └─ 成功 → 写 cache → 更新 displayState
      └─ 面板 0.2s 淡入 + 状态栏同步；popover 保持打开
```

**刷新**

```
RefreshScheduler (Timer 900s | 唤醒 | 联网恢复 | 用户点击刷新)
  → store.refresh()
      ├─ 并发：定位（若 active.isCurrentLocation）→ 更新坐标
      ├─ ProviderRegistry.resolve → 主源 fetch（8s 超时）
      ├─ 失败 → CircuitBreaker 记一次 → 降级链下一源（总预算 12s）
      ├─ AstroCalculator.compute(date, place)  (纯计算，主线程外)
      ├─ 组装 WeatherSnapshot(servedBy:) → 写 cache
      └─ @MainActor 更新 → 状态栏文字/图标 + 面板刷新 + 归属文案
  全源失败 → 指数退避 30s/60s/120s（上限 10 min），保留旧数据，显示"更新于 X 分钟前"
```

#### 4.1.2 选型结论

| 角色 | 提供商 | 理由 |
|---|---|---|
| **默认（零配置）** | Open-Meteo | 无 Key 即可用，CI 不需要任何 secret，新用户开箱有数据 |
| **高精度（推荐）** | Apple WeatherKit | macOS 13+ 原生框架、无需自建 JWT、50 万次/月足够个人用 |
| **国内首选** | 和风天气 | 5 万次/月免费、中文地名、预警齐全、文档最好 |
| **备用** | 心知 / 彩云 / 高德 | 覆盖国内细分需求（分钟级降水、adcode 查询） |
| **兜底** | MET Norway / 7Timer / wttr.in | 全部免 Key，前两者挂掉时仍能出数 |

**默认策略**：`自动`模式 —— 中国大陆坐标优先和风（若配置了 Key）→ 否则 WeatherKit（若会员可用）→ 否则 Open-Meteo；海外坐标 WeatherKit → Open-Meteo。

#### 4.8.2 注册表与自动选择

```swift
// Services/Providers/ProviderRegistry.swift
final class ProviderRegistry {
    private var providers: [ProviderID: WeatherProvider] = [:]

    func register(_ p: WeatherProvider) { providers[p.id] = p }

    /// auto 模式的决策顺序
    func resolve(preference: ProviderID, place: Place) -> [WeatherProvider] {
        if preference != .auto, let p = providers[preference], p.isConfigured() {
            return [p] + fallbackChain(for: place, excluding: preference)
        }
        return fallbackChain(for: place, excluding: nil)
    }

    private func fallbackChain(for place: Place, excluding: ProviderID?) -> [WeatherProvider] {
        let inChina = GeoFence.isMainlandChina(place.latitude, place.longitude)
        let order: [ProviderID] = inChina
            ? [.qweather, .seniverse, .weatherKit, .openMeteo, .metNorway]
            : [.weatherKit, .openMeteo, .metNorway, .sevenTimer]
        return order
            .filter { $0 != excluding }
            .compactMap { providers[$0] }
            .filter { $0.isConfigured() && !CircuitBreaker.shared.isOpen($0.id) }
    }
}
```

**auto 决策表**

| 坐标 | 优先顺序 |
|---|---|
| 中国大陆（GCJ-02 范围内，`isMainlandChina`） | 和风 → 心知 → WeatherKit → Open-Meteo → MET Norway |
| 港澳台 / 海外 | WeatherKit → Open-Meteo → MET Norway → 7Timer |
| 全部源不可用 | 显示缓存 + 离线态 |

**WeatherKit 的两种接入**

| 方式 | 前提 | 优点 | 缺点 |
|---|---|---|---|
| 原生 `WeatherService` 框架 | Apple Developer 会员 + App ID 勾选 WeatherKit + 签名 | 无 JWT、无密钥管理、代码 3 行 | CI 需证书签名（当前 ad-hoc 签名**不可用**） |
| REST API + JWT | 会员 + Service ID + p8 Key | ad-hoc 签名也能用，CI 只需 Secrets | 需自己签 ES256 JWT（每 1 小时刷新） |

> **决策**：默认走 **REST + JWT**，因为当前 CI 用 ad-hoc 签名，原生框架的 entitlement 校验过不去。用户若自备开发者证书本地签名，可切到原生框架（设置里显示"检测到可用 WeatherKit 框架"）。

#### 4.10.3 JWT 生成（WeatherKit REST）

```swift
// Services/Providers/WeatherKitJWT.swift
import CryptoKit

struct WeatherKitJWT {
    let teamID: String      // ABCDE12345
    let serviceID: String   // com.catclever.weatherbar
    let keyID: String       // XXXXXXXXXX
    let privateKeyPEM: String

    func token(now: Date = .init()) -> String {
        let header = #"{"alg":"ES256","kid":"\#(keyID)","typ":"JWT"}"#
        let iat = Int(now.timeIntervalSince1970)
        let exp = iat + 3600
        let payload = #"{"iss":"\#(teamID)","iat":\#(iat),"exp":\#(exp),"sub":"\#(serviceID)}"#
        let signingInput = "\(b64(header)).\(b64(payload))"
        let key = try! P256.Signing.PrivateKey(pemRepresentation: privateKeyPEM)
        let sig = try! key.signature(for: Data(signingInput.utf8))
        return "\(signingInput).\(b64url(sig.rawRepresentation))"
    }
}
```

- 缓存 token 至 `exp - 300s`，过期前 5 分钟重签。
- `p8` 私钥来源：用户粘贴（Keychain）或 CI Secret 注入。

### 4.11 降级、熔断与可观测

| 机制 | 规则 |
|---|---|
| **降级链** | 主源抛错 → 依次尝试 `fallbackChain`，首个成功即返回，并记录 `servedBy` |
| **熔断** | 同一源连续 3 次失败 → 打开 5 分钟；期间跳过该源 |
| **额度耗尽** | HTTP 429 / 403 / `"code":"402"` → 标记该源"今日额度用尽"，当天不再尝试，面板提示 |
| **超时** | 每源 8 s；总预算 12 s（并行竞速可优化为 6 s 内返回首个成功） |
| **并发去重** | 同一 `(providerID, place)` 的 in-flight 请求复用同一个 `Task` |
| **缓存** | `cache/<providerID>-<placeID>.json`，切换源不污染；TTL 15 min |
| **可观测** | 快照里带 `servedBy` / `latencyMs` / `fallbackCount`，设置页"诊断"可看；不上报任何用户坐标 |

**来源展示**：面板底部一行小字 + 图标 —— `数据来源：Weather (Apple)` / `Open-Meteo` / `和风天气`，点击跳转归属页。

## 5. 地区管理

### 5.1 概念模型

| 概念 | 说明 |
|---|---|
| **地区（Place）** | 一条可切换的天气坐标，含名称、经纬度、时区 |
| **当前定位** | 特殊地区，`isCurrentLocation = true`，坐标由 CoreLocation 动态给出，名称由反查得到；不占用收藏名额，不可删除 |
| **收藏地区** | 用户搜索添加的固定城市，上限 12 个 |
| **当前地区（active）** | 面板与状态栏展示的那一个，持久化 |

> 首次启动若无任何收藏，列表 = `[当前定位]`。定位被拒 → 列表 = `[默认地区：上海]`，并在引导中提示手动添加。

### 5.2 存储结构

```swift
// State/PlaceStore.swift
@MainActor
final class PlaceStore: ObservableObject {
    @Published private(set) var places: [Place] = []      // 含"当前定位"虚拟项
    @Published private(set) var activeID: UUID?

    var active: Place? { places.first { $0.id == activeID } }

    private let key = "places.v2"
    private let activeKey = "activePlaceID"
}
```

| Key | 类型 | 内容 |
|---|---|---|
| `places.v2` | `[Place]` JSON | 地区列表（顺序即显示顺序） |
| `activePlaceID` | UUID 字符串 | 当前地区 |
| `cache/<placeID>.json` | 文件 | 该地区最近一次快照（切换回来秒显） |
| `onboarding.completed` | Bool | 引导是否已完成 |

**切换语义**：`setActive(id)` → 写 `activePlaceID` → `WeatherStore.refresh()` → 若 `cache/<id>.json` 存在则**先渲染缓存**再拉新数据。

### 5.3 设置地区（搜索添加）

```
点击地区名 → 切换列表底部"＋ 添加地区…"
  → RegionSearchView（面板内二级页面，返回箭头回主面板）
      ├─ 搜索框（自动聚焦，300 ms 防抖，≥2 字符触发）
      ├─ 结果列表：名称 · 省份/国家 · 经纬度；点击即添加并切换
      ├─ "使用当前位置"（请求定位权限 → 反查名称 → 添加/激活）
      └─ 空态："输入城市名，如 上海 / Tokyo / New York"
```

**搜索实现**

- 端点：`https://geocoding-api.open-meteo.com/v1/search?name={q}&count=8&language=zh&format=json`
- 防抖：`Task.sleep(300ms)`，新输入取消旧任务；**中文输入法中间态**（marked text）期间不请求。
- 去重：同名同坐标（距离 < 1 km）不重复添加，改为"已存在，直接切换"。
- 结果模型映射：`name` / `admin1` / `country` / `latitude` / `longitude` / `timezone`。

### 5.4 切换地区（4 个入口）

| 入口 | 位置 | 交互 |
|---|---|---|
| **① 面板点地区名** | 实况区标题行 | 点击 → 地区名下方 inline 展开 `RegionSwitcherView`（下拉卡片，非新窗口）；选中即切换并收起 |

```
├────────────────────────────────┤
```

### 5.5 定位策略

- **请求时机**：仅在以下三种情况请求 —— ① 首次引导点"使用当前位置"；② 用户显式点"使用当前位置"；③ 启动时 `active.isCurrentLocation == true`。
- **权限**：`requestWhenInUseAuthorization()` → `requestLocation()`（单次）。拒绝后不再弹窗骚扰，改为引导用户手动选地区。
- **反查地名**：`CLGeocoder.reverseGeocodeLocation`，取 `subLocality` / `locality` / `administrativeArea` 组合（参考图 `Pengpu Xincun Diyi` 即 subLocality + locality 风格）。
- **节流**：定位结果缓存 6 h 或位移 > 5 km 才重取。
- **失败兜底**：定位失败 → 保留上次坐标，状态栏照常显示，面板提示"定位失败，显示上次位置"。

### 5.6 边界情况

| 情况 | 处理 |
|---|---|
| 列表为空且定位被拒 | 自动插入默认地区"上海"，引导用户添加 |
| 收藏达上限 12 | "添加地区"按钮置灰，提示"最多 12 个地区" |
| 添加已存在地区 | 不重复插入，直接切换并提示"已切换" |
| 当前地区被删除 | 自动切到列表第一项；列表空则回退默认地区 |
| 跨时区地区 | 一律用该地区 `timezone` 渲染时间；面板标注时区缩写（如 `JST`） |
| 切换中快速连点 | 请求去重：同一 place 的 in-flight 请求复用，旧请求 `cancel()` |
| 无网络切换新地区 | 显示该地区缓存（若有），否则空态"暂无数据，等待联网" |

### 5.7 首次启动：状态栏指引

```swift
@MainActor
final class StatusItemController: NSObject {
    private let store: WeatherStore
    private let prefs: PreferencesStore
    private let statusItem: NSStatusItem

    private var hosting: NSHostingController<AnyView>?
    private var outsideMonitor: Any?

    init(store: WeatherStore, prefs: PreferencesStore) {
        self.store = store
        self.prefs = prefs
        self.statusItem = NSStatusBar.system.statusItem(withLength: NSStatusItem.variableLength)
        super.init()
    }

    func install() {
        guard let button = statusItem.button else { return }
        button.target = self
        button.action = #selector(handleClick(_:))
        button.sendAction(on: [.leftMouseUp, .rightMouseUp])
        button.imagePosition = .imageLeading
        button.font = .monospacedDigitSystemFont(ofSize: 12, weight: .medium)

        popover.behavior = .transient
        popover.animates = true

        observeStore()
        render()
    }

    private var cancellables = Set<AnyCancellable>()

    private func observeStore() {
        // Combine：displayState 变化即重绘状态栏
        store.$displayState
            .receive(on: RunLoop.main)
            .sink { [weak self] _ in self?.render() }
            .store(in: &cancellables)
    }

    private func render() {
        guard let button = statusItem.button else { return }
        let s = store.displayState
        let cfg = NSImage.SymbolConfiguration(pointSize: 13, weight: .regular)
        let img = NSImage(systemSymbolName: s.symbolName, accessibilityDescription: s.symbolDescription)?
            .withSymbolConfiguration(cfg)
        img?.isTemplate = true
        button.image = img
        button.attributedTitle = NSAttributedString(
            string: " " + s.temperatureText,
            attributes: [.font: NSFont.monospacedDigitSystemFont(ofSize: 12, weight: .medium)]
        )
        button.appearsDisabled = s.isStale
    }

    @objc private func handleClick(_ sender: NSStatusBarButton) {
        guard let event = NSApp.currentEvent else { return }
        if event.type == .rightMouseUp || event.modifierFlags.contains(.control) {
            showMenu()
        } else {
            togglePopover()
        }
    }

    private func togglePopover() {
        if popover.isShown { popover.performClose(nil); return }
        guard let button = statusItem.button else { return }
        let root = PopoverRootView()
            .environmentObject(store)
            .environmentObject(prefs)
        let controller = NSHostingController(rootView: AnyView(root))
        controller.view.frame.size = NSSize(width: 360, height: 640)
        popover.contentViewController = controller
        popover.show(relativeTo: button.bounds, of: button, preferredEdge: .minY)
        NSApp.activate(ignoringOtherApps: true)
    }

    private func showMenu() {
        let menu = NSMenu()
        menu.addItem(withTitle: "刷新", action: #selector(refreshNow), keyEquivalent: "r").target = self
        menu.addItem(.separator())
        menu.addItem(withTitle: "设置…", action: #selector(openSettings), keyEquivalent: ",").target = self
        menu.addItem(.separator())
        menu.addItem(withTitle: "退出", action: #selector(quit), keyEquivalent: "q").target = self
        statusItem.menu = menu
        statusItem.button?.performClick(nil)
        statusItem.menu = nil   // 用完即摘，避免影响左键
    }

    @objc private func refreshNow() { Task { await store.refresh(force: true) } }
    @objc private func openSettings() { /* 打开 Settings 窗口 */ }
    @objc private func quit() { NSApp.terminate(nil) }
```

### 8.3 状态存储

```swift
// State/WeatherStore.swift
import Foundation
import Combine

@MainActor
final class WeatherStore: ObservableObject {
    struct DisplayState: Equatable {
        var temperatureText: String = "--°"
        var symbolName: String = "arrow.triangle.2.circlepath"
        var symbolDescription: String = "加载中"
        var isStale: Bool = false
    }

    @Published private(set) var snapshot: WeatherSnapshot?
    @Published private(set) var phase: Phase = .idle
    @Published private(set) var lastError: String?
    @Published private(set) var displayState = DisplayState()

    enum Phase: Equatable { case idle, loading, loaded, failed(String) }

    private let prefs: PreferencesStore
    private let client: WeatherAPIClient
    private let cache: SnapshotCache
    private let astro: AstroCalculator
    private let locator: LocationService
    private var backoff: TimeInterval = 30
    private var task: Task<Void, Never>?

    init(prefs: PreferencesStore, client: WeatherAPIClient, cache: SnapshotCache,
         astro: AstroCalculator, locator: LocationService) { /* 赋值 */ }

    func bootstrap() async {
        if let cached = cache.load() {
            apply(cached, stale: true)
        }
        await refresh()
    }

    func refresh(force: Bool = false) async {
        task?.cancel()
        task = Task { [weak self] in await self?.performRefresh(force: force) }
        await task?.value
    }

    private func performRefresh(force: Bool) async {
        phase = .loading
        do {
            let place = try await resolvePlace()
            let raw = try await client.fetch(latitude: place.latitude,
                                             longitude: place.longitude,
                                             timezone: place.timezone)
            let astroInfo = await astro.compute(for: Date(), at: place, tz: raw.timezone)
            let snap = WeatherSnapshotBuilder.build(raw: raw, place: place, astro: astroInfo)
            cache.save(snap)
            apply(snap, stale: false)
            phase = .loaded
            lastError = nil
            backoff = 30
        } catch {
            phase = .failed(error.localizedDescription)
            lastError = error.localizedDescription
            scheduleRetry()
        }
    }

    private func apply(_ snap: WeatherSnapshot, stale: Bool) {
        snapshot = snap
        let unit = prefs.temperatureUnit
        displayState = DisplayState(
            temperatureText: Formatters.temperatureShort(snap.current.temperature, unit: unit),
            symbolName: snap.current.code.symbolName(isDay: snap.current.isDay),
            symbolDescription: snap.current.code.localizedDescription,
            isStale: stale
        )
    }

    private func scheduleRetry() {
        backoff = min(backoff * 2, 600)
        Task { try? await Task.sleep(for: .seconds(backoff)); await refresh() }
    }

    func persistBeforeExit() { if let s = snapshot { cache.save(s) } }
}
```

```swift
// Services/WeatherAPIClient.swift
import Foundation

protocol WeatherAPIClient: Sendable {
    func fetch(latitude: Double, longitude: Double, timezone: String?) async throws -> OpenMeteoResponse
}

struct OpenMeteoClient: WeatherAPIClient {
    private let session: URLSession = {
        let c = URLSessionConfiguration.ephemeral
        c.timeoutIntervalForRequest = 8
        c.timeoutIntervalForResource = 15
        c.httpAdditionalHeaders = ["User-Agent": "WeatherBar/1.0 (macOS)"]
        return URLSession(configuration: c)
    }()

    func fetch(latitude: Double, longitude: Double, timezone: String?) async throws -> OpenMeteoResponse {
        var comps = URLComponents(string: "https://api.open-meteo.com/v1/forecast")!
        comps.queryItems = [
            .init(name: "latitude", value: String(latitude)),
            .init(name: "longitude", value: String(longitude)),
            .init(name: "current", value: "temperature_2m,relative_humidity_2m,apparent_temperature,is_day,precipitation,weather_code,cloud_cover,pressure_msl,wind_speed_10m,wind_direction_10m,wind_gusts_10m"),
            .init(name: "hourly", value: "temperature_2m,weather_code,precipitation_probability,dew_point_2m,visibility,uv_index,wind_speed_10m,relative_humidity_2m"),
            .init(name: "daily", value: "weather_code,temperature_2m_max,temperature_2m_min,sunrise,sunset,daylight_duration,uv_index_max,precipitation_probability_max,wind_speed_10m_max,wind_gusts_10m_max"),
            .init(name: "timezone", value: timezone ?? "auto"),
            .init(name: "forecast_days", value: "7"),
            .init(name: "wind_speed_unit", value: "kmh"),
        ]
        let (data, resp) = try await session.data(from: comps.url!)
        guard let http = resp as? HTTPURLResponse else { throw WeatherError.network }
        guard (200..<300).contains(http.statusCode) else { throw WeatherError.http(http.statusCode) }
        do {
            return try JSONDecoder.openMeteo.decode(OpenMeteoResponse.self, from: data)
        } catch {
            throw WeatherError.decoding(error)
        }
    }
}

extension JSONDecoder {
    /// Open-Meteo 返回的 "2026-10-27T15:00" 为"本地墙钟时间"，按无时区解析
    static let openMeteo: JSONDecoder = {
        let d = JSONDecoder()
        let f = DateFormatter()
        f.locale = Locale(identifier: "en_US_POSIX")
        f.timeZone = TimeZone(secondsFromGMT: 0)   // 仅作容器，语义由调用方解释
        f.dateFormat = "yyyy-MM-dd'T'HH:mm"
        let df = DateFormatter(); df.locale = f.locale; df.timeZone = f.timeZone
        df.dateFormat = "yyyy-MM-dd"
        d.dateDecodingStrategy = .custom { decoder in
            let s = try decoder.singleValueContainer().decode(String.self)
            if let date = f.date(from: s) ?? df.date(from: s) { return date }
            throw DecodingError.dataCorrupted(.init(codingPath: decoder.codingPath,
                                                    debugDescription: "Bad date: \(s)"))
        }
        return d
    }()
}
```

### 8.5 天文计算（纯函数）

```swift
// Services/AstroCalculator.swift
struct AstroCalculator: Sendable {
    /// 太阳高度角（度），NOAA 简化算法
    func solarAltitude(date: Date, latitude: Double, longitude: Double) -> Double { /* … */ }

    /// 求当天太阳高度角等于 target 的两个时刻（升/降）
    private func solarEvents(date: Date, lat: Double, lon: Double,
                             altitude target: Double) -> (rise: Date?, set: Date?) { /* … */ }

    func compute(for date: Date, at place: Place, tz: String) async -> AstroInfo {
        let lat = place.latitude, lon = place.longitude
        let dayStart = Calendar.current.startOfDay(for: date)

        let (sunrise, sunset) = solarEvents(date: dayStart, lat: lat, lon: lon, altitude: -0.833)
        let (civilDawn, civilDusk) = solarEvents(date: dayStart, lat: lat, lon: lon, altitude: -6)
        let (nautDawn, nautDusk)  = solarEvents(date: dayStart, lat: lat, lon: lon, altitude: -12)
        let (astroDawn, astroDusk) = solarEvents(date: dayStart, lat: lat, lon: lon, altitude: -18)
        let (goldStart, _) = solarEvents(date: dayStart, lat: lat, lon: lon, altitude: -4)
        let (_, goldEnd)   = solarEvents(date: dayStart, lat: lat, lon: lon, altitude: 6)
        let (blueStart, _) = solarEvents(date: dayStart, lat: lat, lon: lon, altitude: -6)

        let phase = moonPhase(for: date)   // Meeus 简化：JDE → 相位角 → 照亮比例
        return AstroInfo(/* … */)
    }

    /// 月相：以 2000-01-06 18:14 UTC 新月为基准，朔望月 29.530588853 天
    func moonPhase(for date: Date) -> MoonPhase {
        let synodic = 29.530588853
        let knownNewMoon = Date(timeIntervalSince1970: 947182440) // 2000-01-06T18:14Z
        let days = date.timeIntervalSince(knownNewMoon) / 86400
        let age = days.truncatingRemainder(dividingBy: synodic)
        let normalizedAge = age < 0 ? age + synodic : age
        let illumination = (1 - cos(2 * .pi * normalizedAge / synodic)) / 2
        return MoonPhase(age: normalizedAge,
                         illumination: illumination,
                         distanceKm: 384_400,      // P1 用 Meeus 第 47 章精算
                         altitude: 0, azimuth: 0)
    }
}
```

> 精度要求：日出日落 ±2 min 足够；月相照亮比例 ±1% 足够。全部纯函数 → 单测可断言固定日期的已知值。

```swift
// State/PlaceStore.swift
import Foundation
import Combine

enum PlaceError: Error { case limitReached(Int), duplicate }

@MainActor
final class PlaceStore: ObservableObject {
    @Published private(set) var places: [Place] = []
    @Published private(set) var activeID: UUID?

    var active: Place? { places.first { $0.id == activeID } }
    var canAddMore: Bool { places.count < maxPlaces }

    private let maxPlaces = 12
    private let defaults: UserDefaults
    private let listKey = "places.v2"
    private let activeKey = "activePlaceID"

    init(defaults: UserDefaults = .standard) {
        self.defaults = defaults
        load()
    }

    // MARK: - 持久化

    private func load() {
        if let data = defaults.data(forKey: listKey),
           let decoded = try? JSONDecoder().decode([Place].self, from: data) {
            places = decoded
        }
        if let raw = defaults.string(forKey: activeKey),
           let id = UUID(uuidString: raw),
           places.contains(where: { $0.id == id }) {
            activeID = id
        } else {
            activeID = places.first?.id
        }
    }

    private func persist() {
        if let data = try? JSONEncoder().encode(places) {
            defaults.set(data, forKey: listKey)
        }
        defaults.set(activeID?.uuidString, forKey: activeKey)
    }

    // MARK: - 变更

    func setActive(_ id: UUID) {
        guard places.contains(where: { $0.id == id }), activeID != id else { return }
        activeID = id
        persist()
    }

    @discardableResult
    func add(_ place: Place) -> Result<Void, PlaceError> {
        if let existing = places.first(where: { $0.isSameLocation(as: place) }) {
            setActive(existing.id)
            return .failure(.duplicate)   // 调用方据此提示"已存在，已切换"
        }
        guard canAddMore else { return .failure(.limitReached(maxPlaces)) }
        places.append(place)
        activeID = place.id
        persist()
        return .success(())
    }

    func remove(_ id: UUID) {
        guard let idx = places.firstIndex(where: { $0.id == id }),
              !places[idx].isCurrentLocation else { return }   // 当前定位不可删
        places.remove(at: idx)
        if activeID == id {
            activeID = places.first?.id
        }
        persist()
    }

    func move(from source: IndexSet, to destination: Int) {
        places.move(fromOffsets: source, toOffset: destination)
        persist()
    }
}
```

## 10. GitHub Actions 构建流水线

### 10.1 设计要点

| 关注点 | 方案 |
|---|---|
| **构建位置** | **只在 GitHub Actions 编译；本地机器零构建**（见 §10.4） |
| Runner | `macos-15`（Xcode 16.x，SDK 15）；Intel 机跑标准 runner，交叉编译出 arm64 切片 |
| 架构 | `ARCHS="arm64 x86_64"` + `ONLY_ACTIVE_ARCH=NO` → Universal 2；`lipo -info` 强校验双切片 |
| 工程生成 | CI 内 `brew install xcodegen` → `xcodegen generate` |
| 编译 | `xcodebuild -scheme WeatherBar -configuration Release`，`ONLY_ACTIVE_ARCH=NO` 出 Universal（arm64 + x86_64） |
| 签名 | 无证书：ad-hoc `CODE_SIGN_IDENTITY=-`；有证书：见 §10.5 |
| 产物 | `WeatherBar.app` → `WeatherBar-<ver>.zip` + `WeatherBar-<ver>.dmg` + `sha256` |
| 上传 | `actions/upload-artifact@v4`（每次构建）/ `softprops/action-gh-release`（打 tag） |
| 缓存 | SPM 缓存 + `xcodegen` brew 缓存（可选） |
| 密钥注入 | 可选 Secrets（`QWEATHER_KEY` / `QWEATHER_HOST`）→ 写入 `Info.plist`；未配置时 Open-Meteo 默认可用 |
| 并发 | `concurrency: cancel-in-progress` 防抖 |
| 触发 | `push: [main]`、`pull_request`、`workflow_dispatch`、`push tags: v*` |

**Universal 2 校验**（CI 强制，失败即红）

```bash
lipo -info "$APP/Contents/MacOS/WeatherBar"
# 期望输出包含：Architectures in the fat file: ... are: x86_64 arm64
for arch in arm64 x86_64; do
  lipo -info "$BIN" | grep -q "$arch" || { echo "::error::missing $arch slice"; exit 1; }
done
```

- 标准 `macos-15` runner 是 **Intel（x86_64）**，Xcode 交叉编译出 arm64 切片，产物仍是 Universal。
- 若想加速，可换 `macos-15-xlarge`（Apple Silicon，付费），但**不改变产物架构**，只是编译更快。
- `LSMinimumSystemVersion` 固定 13.0：覆盖 macOS Ventura 及以上的 Intel Mac（2017 年后机型）与全部 Apple Silicon。

### 10.2 `.github/workflows/build.yml`

```yaml
name: build

on:
  push:
    branches: [main]
    paths-ignore: ['docs/**', '**.md']
  pull_request:
  workflow_dispatch:

concurrency:
  group: build-${{ github.ref }}
  cancel-in-progress: true

env:
  SCHEME: WeatherBar
  CONFIG: Release

jobs:
  build:
    name: Build (universal, unsigned)
    runs-on: macos-15
    timeout-minutes: 30

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Toolchain info
        run: |
          xcodebuild -version
          swift --version
          sw_vers

      - name: Install XcodeGen
        run: brew install xcodegen

      - name: Generate project
        run: xcodegen generate --spec project.yml

      - name: Build
        run: |
          set -o pipefail
          xcodebuild \
            -project WeatherBar.xcodeproj \
            -scheme "$SCHEME" \
            -configuration "$CONFIG" \
            -derivedDataPath build \
            -destination 'generic/platform=macOS' \
            ARCHS="arm64 x86_64" \
            ONLY_ACTIVE_ARCH=NO \
            CODE_SIGN_IDENTITY="-" \
            CODE_SIGNING_REQUIRED=NO \
            CODE_SIGNING_ALLOWED=NO \
            build | xcbeautify || xcodebuild \
            -project WeatherBar.xcodeproj \
            -scheme "$SCHEME" \
            -configuration "$CONFIG" \
            -derivedDataPath build \
            -destination 'generic/platform=macOS' \
            ARCHS="arm64 x86_64" \
            ONLY_ACTIVE_ARCH=NO \
            CODE_SIGN_IDENTITY="-" \
            CODE_SIGNING_REQUIRED=NO \
            CODE_SIGNING_ALLOWED=NO \
            build

      - name: Verify binary
        run: |
          APP="build/Build/Products/$CONFIG/WeatherBar.app"
          test -d "$APP"
          lipo -info "$APP/Contents/MacOS/WeatherBar"
          /usr/libexec/PlistBuddy -c 'Print :CFBundleShortVersionString' "$APP/Contents/Info.plist"

      - name: Ad-hoc sign
        run: |
          APP="build/Build/Products/$CONFIG/WeatherBar.app"
          codesign --force --deep --sign - --options runtime "$APP"
          codesign --verify --verbose=2 "$APP"

      - name: Package (zip + dmg + sha256)
        run: |
          set -euo pipefail
          VERSION=$(/usr/libexec/PlistBuddy -c 'Print :CFBundleShortVersionString' \
            "build/Build/Products/$CONFIG/WeatherBar.app/Contents/Info.plist")
          OUT="dist"; mkdir -p "$OUT"
          APP="build/Build/Products/$CONFIG/WeatherBar.app"
          cp -R "$APP" "$OUT/"
          (cd "$OUT" && ditto -c -k --keepParent WeatherBar.app "WeatherBar-${VERSION}.zip")
          hdiutil create -volname "WeatherBar ${VERSION}" \
            -srcfolder "$APP" -ov -format UDZO "$OUT/WeatherBar-${VERSION}.dmg"
          (cd "$OUT" && shasum -a 256 WeatherBar-* > SHA256SUMS.txt)
          ls -lh "$OUT"

      - name: Upload artifacts
        uses: actions/upload-artifact@v4
        with:
          name: WeatherBar-${{ github.sha }}
          path: dist/*
          retention-days: 14
          if-no-files-found: error
```

> `xcbeautify` 未安装时上面的 `||` 分支会回退到原生输出；更干净的做法是先 `brew install xcbeautify` 再单条构建。文档定稿时二选一，实现阶段用后者。

### 10.4 构建策略：本地零编译，云端唯一构建

**硬约束**：开发机上**不执行** `xcodebuild` / `swift build` / `xcodegen generate` / 任何编译动作。
所有编译、签名、打包、发布均在 GitHub Actions 完成。本地只做两件事：**写代码**、**用 `gh` 驱动远端**。

| 动作 | 本地 | CI |
|---|---|---|
| 写/改源码 | ✅ | — |
| `git commit` / `push` | ✅ | — |
| 生成 `.xcodeproj` | ❌ | ✅ `xcodegen generate` |
| 编译 / 链接 | ❌ | ✅ `xcodebuild` |
| 签名 / 打包 dmg | ❌ | ✅ |
| 产物获取 | ✅ `gh run download` | ✅ artifact |
| 发版 | ✅ `git push --tags` | ✅ Release |

**理由**

- 本地无完整 Xcode 工程（`xcodeproj` 不入库），避免"我这能跑"式环境漂移。
- 编译环境与产物环境一致：谁构建谁发布，产物可复现。
- 本地磁盘不产生 `build/`、`DerivedData/` 等中间物。

**本地唯一允许的校验方式**

```bash
gh workflow run build.yml --ref main   # 触发云端构建
gh run watch                            # 盯进度
```

`scripts/ci.sh` 封装上述命令（**只调用 gh，不编译**）：

```bash
#!/usr/bin/env bash
# 本地仅用于驱动远端 CI，不执行任何编译
set -euo pipefail
cmd=${1:-status}

case "$cmd" in
  build)   gh workflow run build.yml --ref "${2:-main}"; sleep 3; gh run list -w build.yml -L 1 ;;
  watch)   gh run watch "$(gh run list -w build.yml -L 1 --json databaseId -q '.[0].databaseId')" ;;
  logs)    gh run view "$(gh run list -w build.yml -L 1 --json databaseId -q '.[0].databaseId')" --log-failed ;;
  fetch)   gh run download "$(gh run list -w build.yml -L 1 --json databaseId -q '.[0].databaseId')" -D ./dist ;;
  release) git tag "v${2:?version required}" && git push origin "v${2}" ;;
  status)  gh run list -L 5 ;;
  *)       echo "usage: ci.sh {build|watch|logs|fetch|release <ver>|status}"; exit 1 ;;
esac
```

## 13. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| Open-Meteo 非商用条款 | 商业化受限 | 商用前切和风/WeatherKit，客户端已协议化，替换 1 个实现即可 |
| **第三方额度用尽/涨价** | 功能不可用 | 多源 + 熔断 + 降级链；额度状态可视化；默认源零密钥 |
| **WeatherKit 原生框架需证书签名** | ad-hoc 签名用不了 | 默认走 REST + JWT；证书可选升级路径 |
| **WeatherKit 归属合规** | 审核/法律风险 | 面板底部强制 `Weather` 商标 + 链接，集中在 `Attribution.swift` |
| **高德按 adcode 查询** | 坐标→行政区需二次请求 | 适配器内两级请求 + adcode 缓存；失败降级到经纬度源 |
| **内置 API Key 被提取** | 额度被盗刷 | 只内置低价值 Key；推荐用户自填；Keychain 存储；支持一键吊销 |
| **Intel Mac 兼容** | 老机器跑不起来 | Universal 2 + 最低 macOS 13；CI 出包后 `lipo -info` 强校验 |
| **`@Observable` 需 macOS 14** | 无法支持 macOS 13 | 全项目用 `ObservableObject`；代码评审卡住该 API |
| 极地日出日落为 null | 面板空白/崩溃 | 模型层 Optional + 视图占位"—" |
| `NSStatusItem` 宽度抖动 | 视觉跳动 | 等宽数字 + 固定格式；极端情况固定 `length` |
| 无签名分发被 Gatekeeper 拦 | 用户打不开 | README 写清 `xattr` 命令；后续买证书签名+公证 |
| macOS 15 菜单栏高度/刘海差异 | 图标被裁 | 用 SF Symbol 13pt + `NSStatusItem.variableLength`，实测三档缩放 |
| **引导浮层定位偏差** | 箭头指错位置 | 以 `button.window.convertToScreen` 为准，多屏按 `frame.contains` 选屏；三档菜单栏高度实测 |
| Swift 6 严格并发报错 | 编译不过 | 服务层 `Sendable`，UI 层 `@MainActor`，模型全 `Sendable` |
| CI 上 `xcodebuild` 与本地 Xcode 版本差异 | 行为不一致 | 固定 runner 镜像（`macos-15`）+ 记录 `xcodebuild -version` 到日志 |
